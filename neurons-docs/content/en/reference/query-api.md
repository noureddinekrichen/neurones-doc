## Overview {#api-overview}

The Neurons APM service (`apm-ingest`) exposes one HTTP API with two roles:

- **Ingestion** — the OpenTelemetry Collector sends traces, logs and metrics to `/v1/*` in OTLP/HTTP JSON format.
- **Query** — the Neurons user interface reads everything it displays from `/api/*`: applications, services, traces, logs, RUM, business transactions, events, alerting, retention and more.

The API exposes **164 operations**: 143 distinct endpoints, plus 21 `/rum/*` aliases of the `/api/rum/*` endpoints (see [Conventions](#api-conventions)).

This page is an overview. The authoritative, always up-to-date contract — parameters, request bodies and response schemas — is the Swagger documentation generated by the service itself.

## Authentication {#api-auth}

Calls are authenticated with a token in an HTTP header:

| Endpoints | Header | Token |
|---|---|---|
| `/api/*` (query endpoints), except those listed below | `X-Neurones-Token` | Query token |
| `/v1/traces`, `/v1/logs`, `/v1/metrics` | `X-Neurones-Token` | Ingestion token |
| `/api/otel-collectors/agent/current`, `/api/otel-collectors/agent/report` | `X-Otel-Agent-Token` | Per-agent token returned at registration |
| `/api/webhooks/apm/transaction-alerts` | Signature headers | Verified by request signature |
| `/api/`, `/api/health`, `/health`, `/metrics` | — | No token (status and monitoring endpoints) |
{firstcol="30"}

`/api/otel-collectors/{config_id}/push` is an internal administration action, triggered from the Neurons administration screens.

A missing or invalid token returns **401**. Never put a token in a URL, in source code or in a browser application.

## Conventions {#api-conventions}

- **Base path.** Query endpoints are under `/api`; ingestion endpoints under `/v1`.
- **Time window.** Most read endpoints take `minutes` (how far back to look) and `offset_minutes` (how far to shift the window into the past). Some troubleshooting endpoints also accept explicit start/end times. Defaults vary per endpoint — see Swagger.
- **Long windows.** For long time ranges, endpoints read pre-aggregated hourly or daily data instead of raw data, which keeps them fast.
- **RUM aliases.** Every `/api/rum/<path>` endpoint is also served at `/rum/<path>`, with the same behavior and the same authentication.
- **Errors.** Errors are returned as JSON `{"detail": "..."}`. Invalid parameters return **422** with the list of validation errors. When the ingestion buffer is full, `/v1/*` endpoints return **429** `{"error": "ingest buffer full"}` with a `Retry-After: 1` header: the sender should retry.

The ingestion endpoints are called by the Neurons OpenTelemetry Collector, not by applications: they accept OTLP/HTTP **JSON** only. Applications send their telemetry to the Collector — see the application onboarding guides.
